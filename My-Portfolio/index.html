About

I build software the way I'd want to use it — reliable first, polished second. Most of my projects start from a real annoyance: a slow food-donation process, a city with no easy way to report a broken drain, a flight booking flow that should take four clicks instead of forty.

On the backend I reach for NestJS or ASP.NET Core depending on the job; on the frontend, React and Next.js. Deep dive

Zero Hunger — Food Donation & Redistribution Platform

Full-stack · solo project

A management system connecting restaurants, collection staff, and distribution activity to route surplus food to people who need it, instead of a landfill.

  • Built the API in ASP.NET Core Web API, with full CRUD across restaurants, food items, employees, collection requests, and distributions.
  • Modeled the relational data in Entity Framework Core — restaurants to foods to collection requests to distributions — and wrote LINQ queries for custom retrieval logic.
  • Added restaurant-wise food lookups that account for preservation time and per-request quantities, so collection staff know what's actually still good to pick up.
  • Validated every input with DTOs and Data Annotations, and used AutoMapper to keep entity-to-DTO mapping consistent across the API.

Stack: C#, ASP.NET Core Web API, Entity Framework Core, LINQ, Microsoft SQL Server, AutoMapper, RESTful APIs, DTOs

Dhaka Road & Drainage Issue Reporting

Full-stack · solo project

An SEO-friendly reporting tool that lets city residents flag road and drainage problems, built with a responsive interface and proper session security.

  • Handled signup and login with bcrypt password hashing, plus JWT authentication for protected routes and session management.
  • Added OTP-based password reset delivered over email via Node Mailer, for the "forgot password" case.
  • Designed RESTful APIs for authentication, authorization, and the report data flow, with Tailwind CSS handling responsive layout across devices.

Stack: TypeScript, NestJS, React.js, Next.js, Tailwind CSS, PostgreSQL, TypeORM, JWT, Bcrypt, Node Mailer
