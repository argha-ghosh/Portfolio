About

I build software the way I'd want to use it — reliable first, polished second. Most of my projects start from a real annoyance: a slow food-donation process, a city with no easy way to report a broken drain, a flight booking flow that should take four clicks instead of forty.

On the backend I reach for NestJS or ASP.NET Core depending on the job; on the frontend, React and Next.js. I'm comfortable moving across a stack rather than staying in one layer, and I care about the parts recruiters don't always see first — auth flows, database relationships, and API design that doesn't fall over under edge cases.

Currently looking for a software engineering or web development role where I can keep shipping things end to end.
